# Manual de usuario

## Catálogo de videos

La pantalla principal presenta filtros y una tabla paginada.

### Buscar por título

1. Ingresar parte del título en el campo Título.
2. Seleccionar Buscar.
3. La lista vuelve a la primera página y muestra coincidencias sin distinguir mayúsculas.
4. Seleccionar Limpiar para retirar los filtros.

### Navegar páginas

Usar el paginador para cambiar página o seleccionar 10, 20 o 50 filas. El encabezado informa total y estado de carga.

### Campos visibles

- Título
- Tipo/extensión
- Tamaño
- Duración
- Calidad
- Resolución
- Fecha de publicación

## Limitaciones conocidas

- El filtro Año está visible, pero el backend aún no lo soporta.
- Nuevo Video y Exportar están visibles, pero no tienen funcionalidad contratada.
- No existe actualmente navegación visible hacia el detalle.
