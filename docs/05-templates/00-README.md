# Plantillas SDD

Crear `docs/02-features/NNN-nombre-feature/` y usar estas plantillas:

| Uso | Plantilla |
|---|---|
| Especificación | [01-feature-spec.md](01-feature-spec.md) |
| Plan e investigación | [02-feature-plan.md](02-feature-plan.md) |
| Tareas y trazabilidad | [03-tasks.md](03-tasks.md) |
| Testing documental | [04-testing.md](04-testing.md) |
| Implementación | [05-implementation.md](05-implementation.md) |
| Release y despliegue | [06-release-deployment.md](06-release-deployment.md) |
| Decisión transversal | [07-adr.md](07-adr.md) |

## Uso

1. Sustituir identificadores y placeholders.
2. Mantener estado, versión, fecha y responsable.
3. Marcar `No aplica` con motivo en lugar de borrar secciones.
4. Mantener IDs trazables entre spec, contrato, casos y tareas.
5. Cumplir los gates de [docs/README](../README.md).

Las plantillas no generan pruebas ni comandos ejecutables.
