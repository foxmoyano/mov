# Architecture Decision Records

Los ADR registran decisiones transversales difíciles de revertir o con impacto en varias features.

| ADR | Estado | Decisión |
|---|---|---|
| [ADR-001](ADR-001-feature-centric-sdd.md) | Aceptado | Documentación SDD centrada en features |
| [ADR-002](ADR-002-documentary-testing.md) | Aceptado | Testing especificado solo como documentación |

Una decisión local de una feature se registra primero en su `research.md`. Se promueve a ADR cuando gobierna al producto completo.
