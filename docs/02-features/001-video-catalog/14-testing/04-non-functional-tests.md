# Casos no funcionales documentales

- Seguridad: no exponer secretos.
- Observabilidad: logging estructurado.
- Accesibilidad: labels, foco y `scope`.
- Integridad: COUNT y datos con filtros equivalentes.
- Resiliencia: conservar detalle ante fallos de imágenes.
- Configuración: secretos externos y API por entorno.
