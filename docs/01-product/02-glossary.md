|---|---|
| Video | Registro UUID con metadatos en PostgreSQL |
| Catálogo | Listado paginado de videos |
| Escena | Imagen ubicada bajo `media/{uuid}/images/` |
| URL firmada | URL temporal generada por el backend |
| Feature | Unidad SDD con spec, plan, tareas y evidencia |
| Gate | Condición necesaria para avanzar de etapa |
